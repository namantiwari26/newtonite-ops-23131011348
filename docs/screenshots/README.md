# Workdesk UI Screenshots

This directory contains visual captures and placeholders for the primary Workdesk interface states:

1. **`login.png`**: The authentication screen with accessible email and password inputs, demo credentials quick-picker, and validation states.
2. **`list-with-filters.png`**: The dense work item data table with server-side filter toolbars (status, priority, team, assignee), search, pagination controls, and active filter chips.
3. **`item-detail-timeline.png`**: The flyout detail panel featuring lifecycle status controls, claim actions, item metadata, unified chronological activity/comment timeline, and discussion composer.
4. **`conflict-banner.png`**: The optimistic concurrency conflict banner (`409 OPTIMISTIC_LOCK_CONFLICT`) alerting users to external changes with an inline "Reload" action.
